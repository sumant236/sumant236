### 🚀 **Selected Projects:**

#### ☁️ [SkyCast Weather](https://github.com/sumant236/SkyCast_weather-app.git)
Developed a real-time weather dashboard using **React and Context API** for efficient state management. Integrated **Open-Meteo** and **Google Geocoding APIs** to provide precise meteorological data and location-based services with a clean, responsive design.

#### ⚡ [BusyBuy E-Commerce](https://github.com/sumant236/BusyBuy_React-Redux.git)
An E-commerce platform built with **React and Redux Toolkit**. Implemented real-time data synchronization using **Firestore** for instant cart updates and managed complex asynchronous data flows using **Redux Thunks**.

#### 💬 [Chatter Box](https://github.com/sumant236/Chatter-Box.git) 
Worked on the full-stack development of **Chatterbox**, a real-time chat application. I focused on building a user-friendly interface that enables instant messaging through **Socket.io** integration for low-latency communication. The project features a secure authentication system and group management tools.

#### 🛒 [HealthKart Clone](https://github.com/sumant236/healthkart-clone.git)
Contributed to a collaborative project to build a functional **E-commerce replica** using React JS and Redux. The project features a dynamic product catalog with **filtering and sorting** options, a synchronized shopping cart, and secure user authentication via OAuth.
